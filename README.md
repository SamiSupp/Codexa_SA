# Codexa_SA Systems

Sitio web institucional de **Codexa_SA Systems** — empresa de desarrollo de software.

> Tecnología, innovación y confianza para construir el futuro.

## Stack

- HTML5 semántico
- CSS3 (variables, grid, glassmorphism)
- JavaScript vanilla (sin frameworks)
- Tipografía: Poppins (Google Fonts)

## Paleta de marca

| Color | Hex |
|-------|-----|
| Navy | `#0D1B3D` |
| Blue | `#1E3A8A` |
| Green | `#10B981` |
| Green light | `#34D399` |
| Gray | `#E5E7EB` |

## Secciones

1. **Hero** — Propuesta de valor + visual con tarjeta glassmorphism
2. **Valores** — Innovación, Confianza, Compromiso, Calidad
3. **Servicios** — Web, Mobile, Cloud, Software a medida, Ciberseguridad, Consultoría
4. **Proceso** — 4 etapas claras
5. **Tecnologías** — Stack completo
6. **Contacto** — Formulario y datos directos

## Uso local

Abrí `index.html` en cualquier navegador moderno, o serví el directorio:

```bash
python3 -m http.server 8000
```
